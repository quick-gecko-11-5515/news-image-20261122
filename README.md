# The World Today — 22 November 2026

Entry for the make.fun bounty "Sum up 22 November's world news in one image"
(`news-image-20261122`).

The program (`main.py`, Python 3.13, standard library only) writes the image
`entry.png` — a front-page summary of the day's world news — to
`/output/entry.png`. The image itself is stored in this repository and the
program simply copies it, so two runs always produce byte-identical output.

Stories pictured: the COP31 climate summit in Antalya running into overtime
over a fossil-fuel deadlock; a tanker ablaze after striking a mine in the
Strait of Hormuz; and Voyager 1 reaching one light-day from Earth — plus
briefs on Mexico, Peru, Ukraine, Ebola, AI-weapons talks, and Gaza.
